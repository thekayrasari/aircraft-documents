# Aviation Document Abbreviations

This reference guide defines common acronyms and abbreviations used throughout aircraft manuals, flight operations documentation, and technical publications in this repository.

---

## Document & Manual Types

| Abbreviation | Full Term | Description |
|---|---|---|
| **ACAP** | Aircraft Characteristics for Airport Planning | Airport planning and compatibility data provided by airframe manufacturers. |
| **AFH** | Airplane Flying Handbook | FAA handbook covering basic piloting techniques and flight maneuvers. |
| **AFM** | Airplane Flight Manual | Regulatory document approved by civil aviation authorities for aircraft operations. |
| **ARFC** | Aircraft Rescue and Firefighting Chart | Emergency response guides for airport firefighters and rescue teams. |
| **CL** | Checklist | Operational step-by-step checklists for normal, abnormal, and emergency procedures. |
| **FCOM** | Flight Crew Operating Manual | Operational manual detailing systems, limitations, and standard operating procedures. |
| **FCTM** | Flight Crew Techniques Manual | Operational guidance and recommended techniques for flight crews. |
| **MEL** | Minimum Equipment List | Document specifying equipment that may be inoperative at dispatch under specified conditions. |
| **NP** | Normal Procedures | Standard procedures performed during routine phases of flight. |
| **PHAK** | Pilot's Handbook of Aeronautical Knowledge | Essential basic aviation knowledge published by the FAA. |
| **POH** | Pilot's Operating Handbook | Document containing operating procedures and limits for general aviation aircraft. |
| **QRH** | Quick Reference Handbook | Cockpit reference manual for rapid execution of non-normal and emergency checklists. |
| **SOP** | Standard Operating Procedures | Established methods and workflows enforced by flight operators. |
| **TTM** | Technical Training Manual | System-level maintenance and engineering training publications. |

---

## Systems & Operations

| Abbreviation | Full Term | Description |
|---|---|---|
| **EIU** | Engine Interface Unit | Avionics unit interfacing engine control units with aircraft flight management systems. |
| **ETOPS** | Extended-range Twin-engine Operational Performance Standards | Rules permitting twin-engine aircraft to fly routes far from diversion airports. |
| **FMS** | Flight Management System | Computerized avionics system automating in-flight navigation and performance calculation. |
| **MCDU** | Multifunction Control and Display Unit | Physical interface terminal used by pilots to interact with the FMS. |
| **PIO** | Pilot Induced Oscillations | Unintended aircraft oscillations caused by coupling between pilot control inputs and aircraft response. |
| **RNP AR** | Required Navigation Performance Authorization Required | Advanced satellite navigation procedures requiring special aircraft capabilities and crew authorization. |
